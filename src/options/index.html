¶ Pilcrow

A writing assistant that runs entirely inside Chrome. Your text is never uploaded, never stored on a server, and works with the network switched off.

Welcome

Pilcrow uses Chrome's built-in Gemini Nano model. The first check downloads the model once (a few gigabytes) and then everything happens locally.

Requirements: Chrome 138+ on desktop, ~22 GB free disk space, and either a GPU with more than 4 GB of VRAM or a 4-core CPU with 16 GB RAM.

Model status

Some APIs are still experimental in Chrome. Pilcrow falls back to the Prompt API whenever a specialised one is missing, so every feature keeps working — enabling the flags below just makes them faster and more precise.

Enable the experimental APIs
  1. chrome://flags/#proofreader-api — precise grammar and spelling ranges
  2. chrome://flags/#rewriter-api — faster rewriting
  3. chrome://flags/#writer-api — faster drafting
  4. Restart Chrome, then reopen this page.

Diagnostics

Runs a real request through every layer — this page, the service worker, the engine host and the content script — and reports exactly where it breaks.

Your data

        

          Pilcrow has no server, no account and no analytics. Text you write is passed to
          Chrome's on-device model and discarded. Your settings, dictionary and snippets are
          stored in Chrome's own extension storage.
